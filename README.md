# Roll-a-Ball Unity 3D

A 3D Unity game developed during my game development learning journey.

The project includes:
- Classic Roll-a-Ball mode
- Endless runner mode inspired by Subway Surfers
- Main menu
- Pause system
- Settings menu
- Coin collection
- Enemy spawning system

# Game Modes

## Classic Mode
Control the ball, collect all pickups, and win the level.

### Features
- Physics-based movement
- Camera follow system
- Collectibles
- Win panel
- Pause menu
- Settings menu

## Endless Mode
Avoid enemies and collect coins as long as possible.

### Features
- Endless gameplay
- Random enemy spawning
- Coin spawning
- Camera animation
- Lose screen
- Lane switching system
